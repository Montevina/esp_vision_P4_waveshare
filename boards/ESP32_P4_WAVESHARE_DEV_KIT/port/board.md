The following firmware is applicable to the Waveshare ESP32-P4 Module Dev Kit
based on ESP32-P4.

This board must be equipped with at least 16 MiB external SPI Flash and PSRAM.
The default configuration enables the ESP32-P4 target, the ESP-VISION 16 MiB
flash layout, hosted ESP32-C6 WiFi/BLE over 4-bit SDIO, 4-bit SDMMC storage on
the on-chip LDO, and the free-running OV5647 MIPI-CSI camera on the shared SCCB
bus (SDA 7, SCL 8). The board has no LCD; camera frames reach the host through
the EV-MUX preview path instead.
